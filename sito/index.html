Wisper

An Android app that lets an industrial field technician file the daily work report without ever touching the phone.

⬇ Download the APK

Android 8 or newer · ~68 MB · install from unknown sources

The problem

A heating and photovoltaic technician spends the day on site with gloves on and both hands busy. The work report — client, job, description, hours, kilometres, expenses — gets filled in at the end of the day, reluctantly, and often badly.

This is not a hypothetical user. It is the daily routine at my father's technical firm, where I build software for industrial clients. I have watched this problem from close up for years.

How it works

  1. Say “Wisper”

    The wake word runs entirely on the phone. Until it is heard, no audio leaves the device and no connection is needed.

  2. Just talk

    The fields fill themselves in on screen while you speak. Correct anything out loud — “no, three hours” — and it updates.

  3. Say “confermo”

    Wisper reads the report back, you confirm, and the row lands in the company Google Sheet. The phone is never touched.

Technician

“Sono andato da Rossi per la manutenzione della caldaia, quattro ore e trenta chilometri.”

Wisper

“Segnato Rossi Impianti, quattro ore e trenta chilometri. Altro, o salvo?”

Technician

“No aspetta, scusa, erano tre ore non quattro.”

Wisper

“Corretto, tre ore segnate.”

The app speaks Italian, because that is who it was built for.

Installing it

  1. Download the APK

    The button above. The file is hosted on GitHub.

  2. Allow the install

    Android will ask permission to install from an unknown source, and Play Protect will warn that the app is unrecognised. That is expected for any app distributed outside the Play Store — tap Install anyway.

  3. Grant the microphone

    On first launch it asks for the microphone and unpacks the offline speech model. This takes a few seconds, once.

Source code: the full project is public on GitHub, including the Google Apps Script that writes to the spreadsheet.

What it is not — yet

This was built in a weekend hackathon. These limits are real and known, and are listed here rather than discovered later.

  • Single user. There is no login and no accounts: the app writes to one spreadsheet, the owner's. A production version needs authentication, one workspace per company, and per-technician permissions.
  • The spreadsheet endpoint is unprotected. The bridge to Google Sheets is a public Apps Script URL. Anyone holding it could write a row. In production it needs a real token.
  • It needs a connection to understand you. The wake word is fully offline, but the reasoning and the save are not. On a site with no signal, Wisper wakes up but cannot yet queue the report for later. That queue is the next thing to build.
  • Noise degrades accuracy. Published Italian speech-recognition benchmarks (~3% word error) are measured on clean studio audio. On a real building site, expect meaningfully worse. This is the honest weak point of the whole idea.
  • The API key ships inside the APK. Acceptable for a sideloaded demo, not for distribution. Production would route model calls through a server the app never authenticates against directly.
